Основные файлы проекта:

UnitTest1.cs - содержит тесты для основного кода проекта. 

Class1 - основной класс проекта. Содержит в себе интерфейс и его функционал: LoadData (чтение из файла - вызывает метод class2), SaveData (запись в файл - вызывает метод class2) и так далее

Class2 - класс для записи/чтения данных из файлов. Принимает форматы: .json, .xml, .yaml (.yml), .csv

Class3 - содержит класс для работы с Csv форматом

Class4 - содержит класс Course, который содержит данные для моей предметной области.
